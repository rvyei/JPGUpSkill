# Student Portfolio Project

## Project Description 

### Introduction
The project is a personal static portfolio web application developed by a first-year student Karlynn Lorah A. Ballenas. It is built as a foundation for showcasing academic progress in Information Technology, it highlights core programming capabilities, web layout design skills, and foundational web development concepts. 

### Problem and Its Setting
As a first-year Information Technology student, having centralize, structured, and visually engaging web page is a need for documenting learning development and to present project results effectively. Furthermore, the project sets to:
-Establish a digital personal brand and online portfolio space
-Learn modern web layout techniques using CSS Flexbox and Grid
-Demonstrate understanding of HTML structural tags
-Practice clean CSS architecture and custom variable management
-Create responsive, accessible web layouts 
-Implement interactive hover states and entry animations 
-Organize project assets and code cleanly 
-Document technical progress for academic evaluation
